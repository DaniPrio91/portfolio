# Portfolio di Danilo Prioli

Portfolio statico compatibile con GitHub Pages.

## Struttura

- `index.html` – pagina principale
- `css/styles.css` – stile responsive
- `cv/Danilo-Prioli-CV.pdf` – CV collegato dal sito

## Pubblicazione su GitHub Pages

1. Sostituisci nel repository i file con quelli di questa cartella.
2. Esegui commit e push sul branch usato da GitHub Pages (`main`, se già configurato così).
3. Attendi qualche minuto e ricarica il sito.

Non sono necessarie librerie esterne o build: il sito usa solo HTML, CSS e JavaScript nativo.
